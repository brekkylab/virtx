---
title: "virtx: microVM sandbox for AI agents"
description: "virtx is a microVM sandbox for AI agents: run commands in an isolated Linux VM from Python, Node.js or Rust, with no Docker or daemon to set up."
---

virtx runs tasks in Linux microVMs from your code, for jobs with dependencies you do not want to install on your machine, or code you do not want to run on it.

Your code asks a virtx server for a sandbox booted from an image, runs commands in it, and keeps what should outlive it in a volume.

## Getting started

Start with [Hello world](/docs/hello-world/) to run a command in a sandbox, on virtx cloud, on your machine, or on your own server.
