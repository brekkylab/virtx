## Create a sandbox

`create_sandbox` takes an image and these options, named here as in Python. Whatever is left out, the server picks.

The image has to be on the server already, pulled or built as [Images](/docs/guides/images/) shows: a create does not pull it, and refuses a tag the server has no image by with `404`.

| Option | Default | What it does |
| --- | --- | --- |
| `vcpus` | 4 | Its CPUs. |
| `memory_mib` | 4096 | Its memory, in MiB. |
| `network` | `True` | `False` blocks its outbound connections and name lookups. With it on, it reaches public addresses, not this host's loopback or private ones. |
| `ports` | none | TCP ports in it to reach from outside, even with `network` off; see [Networks and ports](/docs/guides/networks-ports/). |
| `name` | none | A name to find it again by, with `find_sandbox`; see [Keeping sandboxes](/docs/guides/keeping-sandboxes/). |
| `auto_stop_minutes`, `auto_delete_days` | 15, 30 | How long it runs unused before it stops, and how long it is kept stopped and unused before it is deleted; see [Keeping sandboxes](/docs/guides/keeping-sandboxes/). |
| `ephemeral` | `False` | `True` deletes it when it stops, rather than keeping it. |
| `volumes` | none | Volumes mounted at paths in it, read-only if asked; see [Mounting volumes](/docs/guides/mounting-volumes/). |
| `gpu`, `gpu_memory_mib` | none | A GPU and the memory it may hold; see [Using GPUs](/docs/guides/using-gpus/). |
| `abins` | none | virtx's own programs, by name, such as `index`, `docread` and `display`, at `/abin` and first on its `PATH`, each with its `SKILL.md` at `/abin/skills/{name}/`. The sandbox answers them as `abins`. |

This makes a sandbox with 2 vCPUs, 2 GiB of memory, and no way out:

<Tabs syncKey="lang">
<TabItem label="Python">

```python
sandbox = await client.create_sandbox(
    "alpine:latest", vcpus=2, memory_mib=2048, network=False
)
```

</TabItem>
<TabItem label="Node.js">

```js
const sandbox = await client.createSandbox('alpine:latest', {
  vcpus: 2,
  memoryMib: 2048,
  network: false,
})
```

</TabItem>
<TabItem label="Rust">

```rust
let args = SandboxCreateArgs::new("alpine:latest")
    .vcpus(2)
    .memory_mib(2048)
    .network(false);
let sandbox = client.create_sandbox(&args).await?;
```

</TabItem>

## Find sandboxes

`list_sandbox` lists every sandbox on the server, `get_sandbox` finds one by its id, and `find_sandbox` by the `name` it was made with, answering none when no sandbox has it. Each comes back, running or stopped, as a sandbox you can run commands in, start, stop or remove, with its `id`, its `name` if it has one, the digest of its `image`, and its `state`, `running` or `stopped`. This is how to find one a program left behind.

<Tabs syncKey="lang">
<TabItem label="Python">

```python
for sandbox in await client.list_sandbox():
    print(sandbox.id, sandbox.name, sandbox.image, sandbox.state.value)

sandbox = await client.get_sandbox("<sandbox id>")
named = await client.find_sandbox("<sandbox name>")
```

</TabItem>
<TabItem label="Node.js">

```js
for (const sandbox of await client.listSandbox()) {
  console.log(sandbox.id, sandbox.name, sandbox.image, sandbox.state)
}

const sandbox = await client.getSandbox('<sandbox id>')
const named = await client.findSandbox('<sandbox name>')
```

</TabItem>
<TabItem label="Rust">

```rust
for sandbox in client.list_sandbox().await? {
    let info = sandbox.info();
    println!("{} {:?} {} {:?}", info.id, info.name, info.image, info.state);
}

let sandbox = client.get_sandbox("<sandbox id>").await?;
let named = client.find_sandbox("<sandbox name>").await?;
```

</TabItem>
</Tabs>

## Remove a sandbox

`remove` deletes a sandbox: it stops it if it runs, ending its jobs, and deletes its disk, what it wrote over its image. Its volumes stay, for the next sandbox to use. To keep a sandbox for later rather than delete it, `stop` it; see [Keeping sandboxes](/docs/guides/keeping-sandboxes/).

<Tabs syncKey="lang">
<TabItem label="Python">

```python
await sandbox.remove()
```

</TabItem>
<TabItem label="Node.js">

```js
await sandbox.remove()
```

</TabItem>
<TabItem label="Rust">

```rust
sandbox.remove().await?;
```

</TabItem>
