`exec_sandbox` takes an argv. Wrap a command in `["sh", "-c", ...]` when it needs a shell.

The returned value is a job. Iterate it to read output lines followed by the exit code, or await it to get the job and its id. A sandbox can run many commands at once, each as its own job. Leaving a loop leaves its command running.

## Execute with a timeout

`timeout_ms` kills the process when the time runs out. This example uses an existing client and sandbox:

<Tabs>
<TabItem label="Python">

```python
async for entry in client.exec_sandbox(sandbox.id, ["sh", "-c", "jq --version"], timeout_ms=10_000):
    match entry.entry:
        case Stdout(line) | Stderr(line):
            print(line)
        case SandboxJobEnd(code):
            print("exited", code)
```

</TabItem>
<TabItem label="Node.js">

```js
const cmd = ['sh', '-c', 'jq --version']
const job = client.execSandbox(sandbox.id, cmd, { timeoutMs: 10_000 })
for await (const entry of job) {
  if ('stdout' in entry) console.log(entry.stdout)
  else if ('stderr' in entry) console.error(entry.stderr)
  else if ('end' in entry) console.log('exited', entry.end.code)
}
```

</TabItem>
<TabItem label="Rust">

```rust
let mut args = SandboxExecArgs::new(["sh", "-c", "jq --version"]);
args.timeout_ms = Some(10_000);
let mut log = client.exec_sandbox(&sandbox.id, &args).log();
while let Some(entry) = log.wait_next() {
    match entry?.entry {
        SandboxJobEntry::Stdout(line) | SandboxJobEntry::Stderr(line) => println!("{line}"),
        SandboxJobEntry::End(end) => println!("exited {}", end.code),
        _ => {}
    }
}
```

</TabItem>
</Tabs>

A command that cannot start, such as one not found, is refused at `exec_sandbox` and creates no job.

## Signal or cancel a job

`signal_sandbox_job` sends a signal such as `SIGTERM` to the job's process group. `remove_sandbox_job` kills a running job's process group and forgets the job.

If a log stream drops, resume with `sandbox_job_log` using `after` and the last entry's `id`. A line longer than 64 KiB arrives as several entries. A long log can include a `truncated` entry and still ends with `end`. See [Jobs and logs](/docs/concepts/jobs/).

## Disable outbound networking

Networking is on by default: the sandbox reaches public addresses, not loopback, private or link-local ones. Pass `network=False` to `create_sandbox` and the sandbox can't open outbound connections or resolve names. Its [ports](/docs/guides/ports/) still accept connections from outside.
