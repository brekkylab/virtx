- [Run commands](/docs/guides/run-commands/): execute commands, stream output, signal them, and set timeouts.
- [Keep work](/docs/guides/keep-work/): restart sandboxes, start on snapshots, commit images, and read and write volume files.
- [Ports](/docs/guides/ports/): forward TCP ports and open HTTP services in a browser.
- [GPU](/docs/guides/gpu/): early access on virtx cloud, and the host's GPU on your own machine.
- [Images](/docs/guides/images/): build recipes, pull and push images, and manage the server's registry.
- [Coding agents](/docs/guides/coding-agents/): install the virtx skill and follow its sandbox workflow.

Start with the [cloud quickstart](/docs/quickstart/) or [Run locally](/docs/local/) to connect a client to a server. Most examples here use that client and `jq:latest`, the image the quickstart builds. Read [Resources](/docs/concepts/resources/) and [Jobs and logs](/docs/concepts/jobs/) for the shared concepts.
